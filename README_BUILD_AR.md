# 7 سنين — النسخة التجريبية (Android)

1. **تحميل الـ APK:** في GitHub افتح المستودع ← تبويب **Actions** ← آخر تشغيل باسم `build-apk` على الفرع `claude/new-session-32a376` ← في أسفل الصفحة حمّل `7senin_demo_apk` (ملف zip) وفكّه لتحصل على `7senin_demo.apk`.
2. **التثبيت:** انقل الملف للهاتف وافتحه، واسمح بـ«التثبيت من مصادر غير معروفة» عندما يطلب الهاتف ذلك.
3. **إعادة البناء:** أي `push` للمستودع يبني APK جديدًا تلقائيًا (Actions). أو محليًا: Godot 4.7.2 ← Project ← Export ← Android ← Export Project.
4. **قائمة المطوّر المخفية:** اضغط 5 مرات بسرعة على الزاوية العلوية اليسرى من الشاشة ← تظهر أزرار القفز (Intro / Station 1 / Gate house / Confrontation / Ending) وزر عدّاد FPS.
5. **النصوص:** كل الحوارات ونصوص الأوراق في `data/dialogue.json` (استبدل كل سطر فيه `MISSING_FROM_STORY` بالنص المعتمد حرفيًا). الأسماء والسنوات في `data/stations.json`.
6. **الأصوات:** ضع ملفًا بنفس الاسم في `audio_custom/` (مثل `cane_1.ogg`) ليحلّ محلّ الصوت المولَّد. لإعادة توليد الأصوات: `python3 tools/make_audio.py`.
7. التحكم على الحاسوب: WASD للمشي، الفأرة للنظر، E للتفاعل، F للمصباح، Space للتثبيت.
